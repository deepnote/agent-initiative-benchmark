Linear contains issues with descriptions, owners, status, priority, dates, labels, comments, relations and change history. Use linear_search_issues with an identifier, text or an empty query to browse. Search does not match comments. Use linear_get_issue for detail and linked records. Search pages have cursors. Detail returns at most 200 comments, oldest first, with comments_truncated when more exist. Team, project, user, status and label catalogs are stored but have no standalone discovery tools here. Links in text are not separate attachments. Oversized detail returns an error.
