BigQuery holds saved service exports, product activity, site operations and warehouse ingestion records. Discover permitted datasets and tables through their catalogs, then inspect a table schema to learn its fields, primary key and partition field. Catalog and schema reads do not scan table rows.
Queries use the same saved baseline and task changes for every role. An overlay row replaces the complete baseline row with the same primary key before filtering or grouping. Use dataset.table names or backtick project.dataset.table names. The SQL engine is DuckDB, with bounded results and a query deadline. JSON fields hold stored source properties. A mirror can lag its source, so use its sync time and native business identity when comparing records. Use explicit dates and useful columns. has_more means another page exists, not that the delivered rows cover the full result.
