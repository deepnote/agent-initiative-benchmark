PostHog contains product events, people, workspace/website groups, event definitions, saved insights and feature flags. Discover native records with posthog_list_catalog using projection=summary to keep saved insight results out of discovery lists. Tested agents default to this explicit summary projection when omitted. Native author/reviewer and proof calls retain the full default. Read a complete stored insight with kind=insights, its returned insight_id and projection=full on the same tool. Full without an ID returns the complete catalog. Summary retains names, definitions, filters, owners, dates and refresh context. Use event_uuid for an exact event. Keep event-time properties separate from current profiles. Read identity history before linking anonymous activity to a person. Use posthog_query_events, posthog_get_event, posthog_query_persons, posthog_query_history and posthog_get_feature_flag for detail. posthog_query_insight computes fresh results over the effective data. Stored insight results are not fresh calculations. Insights cover trends, funnels, retention, paths, stickiness and lifecycle within supported definitions and resource limits. Missing history is unavailable.
