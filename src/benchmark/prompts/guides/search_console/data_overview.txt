Search Console provides stored performance, property/page/query catalogs and URL inspections for the pinned property and configured read grant. Performance dates are inclusive and cannot pass the task snapshot. Read all pages using nextStartRow while hasMore is true. Reports use the complete effective rows before filtering, grouping, sorting and paging. CTR is total clicks divided by total impressions. Average position is total position_sum divided by total impressions. Query breakdowns and query filters exclude privacy-hidden queries. Property totals can include their metrics, so visible queries need not sum to those totals. Catalogs and exact reads never reveal hidden query text. Page catalogs retain stored catalog fields. Use the inspection read for effective index, crawl and canonical state. Inspections are stored snapshots, not live Google checks. observedAt is available only when stored. lastCrawlTime is not the inspection observation time. An unavailable observation time cannot prove when an inspection was taken. Viewer-only sitemap summaries, indexing trends, video URLs, Web Vitals, HTTPS and link summaries are unavailable measured evidence. Stored sitemap/referring URL fields inside an inspection remain that snapshot's fields, not separate measured reports. The exact supplied tools define your access.
