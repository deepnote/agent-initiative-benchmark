Search current and historical Slack messages. Case-insensitive text terms all must match; quoted text is a literal phrase. Filters: in:channel-name-or-ID, from:user-name-or-ID, after:YYYY-MM-DD (inclusive UTC midnight), before:YYYY-MM-DD (exclusive), on:YYYY-MM-DD, has:link, has:reaction, has:file. No OR/NOT or semantic search. Returns messages, total, has_more and next_cursor. Messages have channel_id, user_id, author, ts, thread_ts, text, datetime, permalink, reactions, blocks and file metadata. File metadata does not provide file content. Score measures text matches. Read the thread for conversation context. Snapshot eligibility differs from whole-day search filters.
