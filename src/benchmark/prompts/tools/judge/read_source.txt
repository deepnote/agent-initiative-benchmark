Read exact fragments of registered original sources. Pass one source_id with its cursor, or a list of up to eight distinct IDs with cursor=null for independent first pages. max_chars applies to each source. A list may request at most 65536 characters in total. List results preserve ID order and return a separate next_cursor for each source. Continue each incomplete source individually until next_cursor is null. Only complete sources are citable. Use registered evidence IDs, not business IDs or document paths. Never infer content from the index alone.
