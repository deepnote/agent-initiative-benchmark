Read a compact CRM record. Default properties are name/domain for companies, firstname/lastname/email for contacts, or dealname/dealstage/amount for deals. Explicit properties retain their full native values. Activities, associations and property history are omitted by default, not absent or counted as zero. Use hubspot_list_activities, hubspot_list_associations and hubspot_read_history for bounded related data. Explicit associations or properties_with_history return associationPage or historyPages with totals and continuation, at most 20 rows per page. Continue associationPage with hubspot_list_associations and object_types=associationObjectTypes. Continue historyPages with hubspot_read_history and the returned order. Keep the same parent and filters. The native record ID is returned as top-level id, outside properties. Select only property names present in the selected object schema. Do not request hs_object_id or another alias unless the readable property definitions actually contain it.
