List readable native property definitions, owners, teams, pipelines or stages. For field choices, set catalog=property_values with object_type and property_name. Authoritative options are labeled authoritative_options. Otherwise observed_values lists native values and record_count from readable effective records, including task replacements. Observations are not a complete allowed schema. Null and empty values remain distinct. Missing properties are not counted. archived selects the record archive state for observations. Use page_size from 1 to 100 and paging.next.after. Property grants apply before values and counts. For one known native owner ID, use catalog=owners and owner_id. Only owners in granted teams are returned. Hidden and missing IDs both return an empty page with total=0. Without owner_id the existing catalog listing is unchanged. Keep owner_id and all other filters when continuing.
